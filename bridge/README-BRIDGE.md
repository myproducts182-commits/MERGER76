# الجسر المحلي لـ Google Flow — دليل التثبيت على Windows

يعمل Google Flow (flow.google) على **اشتراكك وكريدتاتك** عبر متصفحك أنت — لا يوجد
API رسمي. هذا الجسر الصغير يربط موقع Flow المفتوح في متصفحك بخادم MCP على Vercel،
فيتحول خادمك إلى مساعد ينفذ أوامر التوليد كما لو كنت تكتبها بنفسك.

**ما لا يحدث أبدًا:** لا كلمات مرور، لا كوكيز، لا جلسات تُرسل للخادم — الجلسة
تبقى داخل متصفحك، والاتصال HTTPS صادر من جهازك فقط (لا منافذ مفتوحة، لا نفق).

## المتطلبات

- **Windows 10/11** مع **Node.js 22+** (من [nodejs.org](https://nodejs.org) — نسخة LTS)
- **Chrome أو Edge** مثبتان (يُكتشف تلقائيًا)
- توكن الجسر `BRIDGE_TOKEN` (نفس القيمة في Vercel وbridge.env)

## خطوات التثبيت (5 دقائق)

### 1) انسخ مجلد `bridge` من المشروع إلى مجلد ثابت على جهازك
مثل `C:\MERGER76-bridge\` — الملفات: `flow-bridge.js`، `install-windows.bat`،
`start-flow-bridge.bat`.

### 2) اضبط التوكن على Vercel
Vercel → مشروع MERGER76 → Settings → Environment Variables → أضف:
- `BRIDGE_TOKEN` = قيمة سرية طويلة (أنشئها بنفسك أو اطلبها من المساعد)

أعد النشر بعد إضافتها (Deployments → Redeploy).

### 3) شغّل `install-windows.bat` (نقرة يمين → تشغيل)
سيقوم تلقائيًا بـ:
- فحص Node.js (يطلب 22+)
- كتابة `bridge.env` بعد أن تلصق فيه التوكن
- إنشاء مهمة مجدولة **لتشغيل الجسر تلقائيًا عند كل تسجيل دخول** (اختياري)
- تشغيل الجسر أول مرة

### 4) اختبر الاتصال بدون أي كريدتات (وضع FAKE)
التثبيت يبدأ بـ `FAKE=1` — محاكاة كاملة بدون متصفح وبدون لمس Flow:
- من ChatGPT (الموصل الحالي نفسه، لا تغيير في الرابط): اطلب **flow_status**
  → يجب أن يظهر الجسر 🟢 متصل
- اطلب **flow_probe** → محاكاة فحص حساب
- اطلب **flow_generate_video** بوصف تجريبي → سترى التقدم 10%→99% ثم ملف وهمي
  يُبث فعليًا عبر رابط flow_download_result (اختبار كامل للقناة والشرائح)

### 5) انتقل للوضع الحقيقي وسجّل دخولك (مرة واحدة)
- في `bridge.env` غيّر `FAKE=1` إلى `FAKE=0`
- شغّل `start-flow-bridge.bat` → يفتح **متصفحًا مخصصًا بجلسة مستقلة**
- سجّل الدخول إلى Google Flow بحسابك داخل هذه النافذة (تبقى محفوظة دائمًا)
- من ChatGPT اطلب **flow_probe** → تأكيد «مسجل الدخول ✅» وقائمة موديلات حسابك
  (Veo 3.1 / Omni Flash / Nano Banana…) — هذا فحص قراءة فقط، صفر كريدتات

### 6) أول توليد حقيقي — بموافقتك
اطلب في ChatGPT مثلًا: «ولّد فيديو 8 ثوانٍ عبر Google Flow لمشهد شروق».
سيستهلك كريدت واحدًا من اشتراكك عبر واجهة الموقع تمامًا. **لا يتم أي توليد
تجريبي إلا بأمرك**.

## أدوات MCP الجديدة (13 أداة الآن — القديمة السبع لم تُمس)

| الأداة | الوظيفة |
|---|---|
| `flow_status` | حالة الجسر والطابور وآخر المهام |
| `flow_generate_video` | توليد فيديو على موقع Flow (كريدتات اشتراكك) |
| `flow_generate_image` | توليد صورة على موقع Flow |
| `flow_upload_reference` | رفع صورة مرجعية إلى المشروع الحالي |
| `flow_check_progress` | متابعة التقدم لحظيًا |
| `flow_download_result` | رابط عام للملف + مساره المحلي على جهازك |

## الأمان

- الاتصال: HTTPS صادر من جهازك + استطلاع طويل — لا منفذ مفتوح ولا رابط عام لجهازك
- المصادقة: ترويسة `X-Bridge-Token` (نفس القيمة على الطرفين، غير مخزنة في الكود)
- الجلسة: في `bridge/flow-profile` على جهازك فقط — لا تُرسل لأي مكان
- النتائج: تُحفظ محليًا في `bridge/results` + تُبث شرائحًا مؤقتة عبر الوسيط (تُحذف بعد ساعتين)

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| `503 BRIDGE_TOKEN غير مضبوط` | أضف المتغير في Vercel وأعد النشر |
| `401 توكن غير صحيح` | تأكد أن القيمة في bridge.env = قيمة Vercel حرفيًا |
| الجسر متصل لكن `probe` يقول غير مسجل | سجّل الدخول في نافذة المتصفح المخصصة التي فتحها الجسر |
| «لم أجد صندوق الوصف / زر الإنشاء» | واجهة Flow تغيّرت — انسخ لي `ui.buttons` من نتيجة probe وسأضبط المحددات |
| التوليد «رُفض» | Flow قد يطلب حلقة تحقق بشرية أحيانًا — أكملها يدويًا في النافذة ثم أعد الأمر |
